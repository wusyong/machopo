# The WPT tests `python3 scripts/test.py wpt` runs (through wptrunner),
# testharness.js tests, reftests and crashtests alike: one file, or a
# directory ending in `/`, per line, under the WPT checkout
# (`../third_party/wpt`). A directory takes every test in it, of every kind;
# a file, the tests it holds (a `.any.js` file's globals, a test's
# variants). A reftest's references, and theirs in turn, need no line: only
# the files that should run as tests of their own. Those that don't run are
# `disabled` in their `.ini` under `metadata/`, with the reason; the tests
# that run but fail have their expected results there. A directory is added
# whole when a feature makes most of it run. How the tests were picked is
# in README.md.
