A Chromium-like browser in Rust. This page is rendered by machopo's pipeline: html5ever, the cppgc-backed DOM, style, taffy + parley layout, paint and cc. V8 runs the script in the box below.

The blue square moves every frame. Only the tiles it passes through are rastered again, not the whole page, only its own style is computed again, only its box takes the new style, the rest of the box tree staying as it is, only it and the boxes it is in are laid out again, the others keeping their fragments, and only it is painted again, the others' display items taken from the last paint: run with RUST_LOG=compositor=debug,style=debug,layout=debug,paint=debug to see how many each frame.
